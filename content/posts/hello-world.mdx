# 블로그를 시작합니다

새로운 블로그를 시작합니다. 개발하면서 배운 것들을 기록하고 공유하는 공간으로 만들어 가겠습니다.

## 왜 블로그인가

- 배운 것을 정리하면 더 오래 기억에 남는다
- 다른 개발자에게 도움이 될 수 있다
- 글쓰기 자체가 사고력을 높여준다

## 앞으로의 계획

주로 다음과 같은 주제를 다룰 예정입니다:

- **Backend** — 서버 개발, API 설계
- **Architecture** — 시스템 설계와 의사결정
- **DevOps** — CI/CD, 인프라

앞으로 잘 부탁드립니다 🙂
